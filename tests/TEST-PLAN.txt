DEFERRED FOR NOW
----------------------

[deferred] Deterministic proof that the opposite detached hook is not started
  Reason: current negative hook tests only confirm that no marker appears during bounded
          post-execution polling; a detached hook could in principle publish later.

[deferred] Interactive stdin inheritance timing / blocking
  Reason: file-fed stdin content inheritance is covered; live console/pipe interaction
          and blocking behavior still need synchronized instrumentation.

[deferred] Fault-injection tests for runtime supervision failures
  Reason: requires deterministic failure injection for IOCP initialization,
          Job Object monitoring, and GetExitCodeProcess failures to verify
          fail-fast behavior under --debug, default non-abort behavior, and
          --abort-on-runtime-failure termination.

[deferred] Exit code 253 for post-execution hook launch failure
  Reason: requires deterministic CreateProcessW failure after successful
          Prepare. Missing hook paths are rejected earlier and do not
          exercise the hook-launch failure path.

[deferred] CancelIoEx with a blocked reader and an external pipe writer
  Reason: requires a helper retaining a pipe write handle outside the managed
          process tree, plus synchronization to verify forced cancellation.
          Ordinary timeout tests do not prove cancellation of a blocked read.

[deferred] Exact Stream-vs-End/replay timing
  Reason: content is covered, but proving arrival while the child is still
          running needs synchronization/timing instrumentation.

[deferred] Exact cross-pipe chronology for mixed stderr / incl-stdout
  Reason: stdout and stderr are drained by separate reader threads; proving
         child write order across both streams needs a synchronized fixture
         or additional instrumentation.
         
[deferred] Exact buffer dropped-byte/event accounting
  Reason: deterministic overflow/abort behavior is covered; exact dropped-byte/event
          accounting still needs a controlled high-volume generator fixture.

[deferred] Extreme argv quoting edge cases
  Reason: ordinary spaces/path quoting are covered; exact empty-argument,
          nested-quote, backslash/quote and tab edge cases are better verified
          with a tiny argc/argv fixture executable than a .cmd script.

[deferred] Per-target FileSink write-failure isolation and latch persistence
  Reason: requires deterministic failure injection for one file target while
          verifying that other targets continue writing and subsequent jobs
          are marked Suppressed rather than Failed.

[deferred] Parent stdout/stderr write-failure isolation
  Reason: requires controlled failure of an inherited output handle while
          keeping the other parent output channel operational.

[deferred] Multiple simultaneous output write failures
  Reason: requires deterministic failures of several independent targets to
          verify individual GLE values and the complete hook environment summary.

[deferred] Output write failure during the final INFO diagnostic
  Reason: requires synchronized failure injection during worker shutdown to
          verify the final exit code and hook environment.

[deferred] CloseFinalWriters failure and stderr emission policy
  Reason: requires deterministic CloseHandle failure injection after output
          workers have stopped, while verifying exit code 255 and that
          --stderr-emit never is respected.
