COVERED IN THIS CMAKE/CTEST SUITE

[covered] Parser / CLI

  - --verbose behavior (implies debug and emits verbose diagnostics) and --inherit-stdin acceptance

[covered] Numeric parsing / boundaries

[covered] Child-output event framing runtime
  - deterministic LF event boundaries for child stdout and child stderr
  - CRLF framing recognizes only exact CRLF; lone LF and lone CR remain payload bytes
  - CRLF threshold ending in CR consumes the following LF as the documented one-byte extension

  - unterminated EOF tails are flushed for both LF and CRLF framing
  - omitted newline-max-bytes applies the 524288-byte default threshold at runtime
  - stdout and stderr-child framing modes and thresholds operate independently
  - byte thresholds may split a multibyte UTF-8 code point; resulting invalid-UTF-8 events
    fall back losslessly to Base64 per event

[covered] Path validation

[covered] cwd

DEFERRED FOR NOW
----------------------

[deferred] Deterministic proof that the opposite detached hook is not started
  Reason: current negative hook tests only confirm that no marker appears during bounded
          post-execution polling; a detached hook could in principle publish later.
[deferred] NUL-containing byte-exact payloads
  Reason: CRLF, exact threshold boundaries, UTF-8 threshold splits, and invalid UTF-8 are covered;
          embedded NUL still needs a dedicated byte-exact fixture/capture case.

[deferred] Interactive stdin inheritance timing / blocking
  Reason: file-fed stdin content inheritance is covered; live console/pipe interaction
          and blocking behavior still need synchronized instrumentation.

[deferred] Process-tree termination proof on timeout
  Reason: needs a child fixture that spawns descendants and records survival.

[deferred] Exact Stream-vs-End/replay timing
  Reason: content is covered, but proving arrival while the child is still
          running needs synchronization/timing instrumentation.

[deferred] Exact cross-pipe chronology for mixed stderr / incl-stdout
  Reason: stdout and stderr are drained by separate reader threads; proving
         child write order across both streams needs a synchronized fixture
         or additional instrumentation.
         
[deferred] Exact buffer dropped-byte/event accounting
  Reason: deterministic overflow/abort behavior is covered; exact dropped-byte/event
          accounting still needs a controlled high-volume generator fixture.

[deferred] Extreme argv quoting edge cases
  Reason: ordinary spaces/path quoting are covered; exact empty-argument,
          nested-quote, backslash/quote and tab edge cases are better verified
          with a tiny argc/argv fixture executable than a .cmd script.
